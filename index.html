Proyecto IoT IFCT80 - Manuel Pires

Estación IoT:
Video Club 3D Ciberfísico

Eliminamos la barrera entre el consumo digital y la automatización física. El usuario explora sus películas en BingeBrowse (un videoclub virtual retro en 3D interactivo) y, al darle al "Play", el entorno físico reacciona sirviendo sus aperitivos y bebidas automáticamente.

El Problema

La preparación de aperitivos rompe la inmersión de la experiencia multimedia, exigiendo tareas manuales y pausas constantes.

La Innovación

Retrofitting de electrodomésticos convencionales para dotarlos de control lógico, telemetría y seguridad de grado industrial.

Arquitectura Distribuida Cliente-Servidor

El sistema separa el pesado renderizado gráfico 3D de la actuación electrónica en tiempo real, maximizando el rendimiento y aislando las cargas de potencia.

Frontend Multimedia

Raspberry Pi 500 (Autologin)

  • Ejecuta Chromium en Modo Kiosco (`--kiosk`), sumergiendo al usuario en el videoclub BingeBrowse a pantalla completa.
  • Un userscript (Tampermonkey) detecta de forma invisible cuándo se inicia la reproducción.
  • Emite la orden de actuación mediante una petición HTTP POST por la red local sin retardo.

Backend / Actuación

Raspberry Pi 3B+ (Headless)

  • Actúa como cerebro físico en la sombra. Recibe las órdenes vía API REST en Flask.
  • Controla directamente los pines GPIO para manejar las cargas de 230V AC y 5V DC.
  • Vigila las interrupciones de seguridad de los sensores y registra la telemetría del sistema.

Control Ciberfísico y Seguridad

Dos módulos independientes gobernados con prioridad en la prevención de accidentes y el control de lazo cerrado.

Subsistema de Sólidos

Palomitero Orbegozo 1000W

  • Actuación Segura: Relé optoacoplado que aísla la fase de 230V del circuito de control lógico (GPIO 17).
  • Diseño Mecánico: Expulsión directa aerodinámica al bol, eliminando la necesidad de motores que puedan atascarse.
  • Lógica: Temporizador asíncrono de cocción (~180s) con capacidad de interrupción manual inmediata.

Subsistema de Fluidos

Dispensador de sobremesa modificado (5V)

  • Lazo Cerrado: Célula de carga + HX711 que detecta la masa real (1g = 1ml), tarando automáticamente cualquier vaso.
  • Conmutación: Transistor MOSFET IRLZ44N equipado con diodo flyback para proteger la placa de picos inductivos.
  • Fail-Safe: Algoritmo vigilante; si el vaso es retirado prematuramente, corta la bomba en milisegundos para evitar derrames.

Software e Interfaz Multipunto

Auditoría, concurrencia y control soberano sobre el hardware.

API & Concurrencia

Servidor Flask multihilo en Python. Gestiona colas de tareas asíncronas para permitir la dispensación de líquido y la cocción de sólidos de forma simultánea, sin congelar el hilo principal.

Telemetría (SQLite)

Cada acción genera una transacción registrada de forma persistente. Los datos se pueden consultar en un dashboard local en red, de forma idéntica a las métricas de explotación comercial.

Control Multicanal

Control remoto mediante un Bot de Telegram integrado. Permite activar rutinas bajo demanda (`/palomitas`) y funciona como un Kill-Switch de emergencia (`/parar`) para mayor seguridad. Control remoto de voz offline (Vosk), garantizando respuesta sin usar la nube.

Hardware y Componentes

Núcleo Informático

  • Raspberry Pi 500 (Frontend BingeBrowse)
  • Raspberry Pi 3B+ (Backend IoT Headless)
  • Micrófono USB mini (Vosk offline)

Electrodomésticos

  • Palomitero Orbegozo PA 4300 (1000W)
  • Dispensador Padwa Lifestyle (modificado)

Potencia y Control

  • Relé optoacoplado 5V (10A/250VAC)
  • MOSFET Canal N (IRLZ44N) + Diodo Flyback
  • Fuente externa 5V/2A para motores

Sensores y Miscelánea

  • Célula de carga (1kg/5kg) + Módulo HX711
  • Caja estanca aislamiento 230V
  • Resistencias, placa perforada y cableado
