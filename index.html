Estación IoT:
Video Club 3D Ciberfísico

Eliminamos la barrera entre el consumo de contenido digital y la automatización del entorno físico mediante una arquitectura inteligente y distribuida.

El Problema

La preparación de aperitivos interrumpe la inmersión del usuario, requiriendo intervención manual y constantes pausas.

La Innovación

Retrofitting de electrodomésticos convencionales para dotarlos de control lógico, telemetría y seguridad de grado industrial.

Arquitectura Distribuida Cliente-Servidor

El sistema separa el pesado renderizado gráfico de la actuación electrónica en tiempo real, maximizando el rendimiento y aislando las cargas de potencia.

Frontend Multimedia

Raspberry Pi 500 (Autologin)

  • Ejecuta Chromium en Modo Kiosco (`--kiosk`), bloqueado visualmente en el videoclub BingeBrowse.
  • Captura el evento "Play" mediante un userscript (Tampermonkey).
  • Emite una petición HTTP POST por la red local sin retardo perceptible.

Backend / Actuación

Raspberry Pi 3B+ (Headless)

  • Actúa como cerebro físico en la sombra. Recibe las órdenes vía API REST en Flask.
  • Controla directamente los pines GPIO para manejar cargas de 230V AC y 5V DC.
  • Procesa las interrupciones de seguridad (sensores) y registra la telemetría del sistema.

Control Ciberfísico y Seguridad

Dos módulos independientes gobernados con prioridad en la prevención de accidentes y el control de lazo cerrado.

Subsistema de Sólidos

Palomitero Orbegozo 1000W

  • Actuación de Potencia: Relé optoacoplado aislando la fase de 230V del circuito de control (GPIO 17).
  • Diseño Mecánico: Expulsión directa aerodinámica al recipiente, eliminando motores y piezas móviles propensas a atascos.
  • Lógica: Temporizador asíncrono de ~180s con capacidad de interrupción.

Subsistema de Fluidos

Dispensador de sobremesa modificado (5V)

  • Lazo Cerrado: Célula de carga + HX711 detecta la masa real (1g = 1ml), tarando automáticamente vasos de entre 15g y 60g.
  • Conmutación: Transistor MOSFET IRLZ44N con diodo flyback para proteger la placa de picos inductivos.
  • Fail-Safe (Emergencia): Algoritmo de caída de peso brusca; corta la bomba en ms si el vaso es retirado prematuramente.

Software e Interfaz Multipunto

Auditoría, concurrencia y control soberano sobre el hardware.

API & Concurrencia

Servidor Flask multihilo en Python. Gestiona colas de tareas asíncronas para permitir la dispensación de fluidos y la cocción de sólidos simultáneamente, sin bloquear el hilo principal.

Telemetría (SQLite)

Cada acción genera una transacción detallada (estado, timestamp, ml exactos, interrupciones). Los datos se visualizan en un dashboard local en red, idéntico a métricas de explotación comercial.

Control Remoto

Soberanía total del usuario vía Bot de Telegram. Permite activar rutinas bajo demanda (`/palomitas`) y actúa como Kill-Switch inalámbrico (`/parar`) para abrir los relés en caso de alerta física.
